# Dungeon-Platformer-Game

2D 사이드뷰 탐험형 플랫포머 + 로그라이크. 1층부터 9층까지 올라가며, 죽으면 처음부터. Phaser 3 + TypeScript + Vite.

**플레이 (미리보기 배포):** https://hzydkz.github.io/Dungeon-Platformer-Game/ — `?seed=12345`로 시드 고정

## 조작

| 동작 | 키보드 | 게임패드 (Xbox 배치) |
|---|---|---|
| 이동 | ←→ / A D | 왼쪽 스틱 / 십자키 |
| 점프 (길게 누르면 높이) | Space / Z | A |
| 공격 (↑/↓ 누르면 위/아래) | X / J | X |
| 역할군 스킬 | C / K | B / RB |
| 포탈 진입, 상자/제단/상점/레버 | ↑ | 스틱 위 / 십자키 위 |
| 발판 아래로 | ↓ + 점프 (공중에서 ↓ 유지) | 같음 |
| 모서리 잡기 | 떨어지면서 벽 쪽으로 방향 유지 | 같음 |
| 매달린 상태: 올라가기 / 놓기 | 점프 / ↓ | A / 스틱 아래 |
| 약도 (누르는 동안 표시, 이동 느려짐) | Tab / M | View / Y |
| 메뉴 결정 / 나가기 | Enter / Space / Z · Esc | A / Menu · B |

개발/미리보기 빌드 디버그: 키보드 `1` 지도 전체 공개, `2` 무적, `3` 다음 층, `4` 히트박스 표시, `5` 보스 즉시 처치.
게임패드는 **LB를 누른 채로** Y 지도 공개, X 무적, Menu 다음 층, 십자키 ↓ 히트박스, B 보스 즉시 처치 (LB를 누르는 동안 이 버튼들은 게임 조작으로 쓰지 않는다). 키보드 없이 패드만으로 모든 조작이 된다.

## 게임 흐름

타이틀 → 캐릭터 선택(후보 3명: 역할군 + 특성 + 성격) → 1층 입구 포탈에서 등장 → 탐사 / 보스(선택) / 빨간 포탈(선택) / 상점 → 출구 파란 포탈 → … → 9층 최종 보스 처치 = 클리어. 사망하면 결과 화면(도달 층, 처치 보스 수, 레벨, 시드, 플레이 시간).

## 성장: 레벨, 골드, 아이템

- **레벨**: 몬스터/보스를 처치하면 경험치. 레벨이 오르면 최대 체력·공격력이 오르고 체력 일부 회복.
- **골드**: 상자(회복 또는 골드), 몬스터, 보스에서 얻는다. 층마다 있는 **상점**(지도에 처음부터 표시)에서 아이템과 회복 물약을 산다.
- **아이템**: 최대 3칸, 가진 동안 효과. 등급 F(흔함)~S(귀함). 보스 처치(3개 중 선택), 빨간 던전 보스, 제단, 상점에서 얻는다. 칸이 가득 차면 어떤 아이템을 뺄지 고른다. 가진 아이템의 효과는 지도(Tab)를 열면 보인다.
- 화면은 창 비율에 맞춰 꽉 채운다 (16:9보다 넓거나 좁으면 보이는 범위가 넓어진다).

## 실행

```bash
npm install
npm run dev            # 개발 서버 (http://localhost:5173)
npm test               # Vitest 단위 테스트 (맵 생성 1,000시드 포함)
npm run typecheck      # 타입 검사 (src / tests)
npm run build          # 정식 빌드 (디버그 기능 꺼짐)
npm run build:preview  # 디버그 기능을 켠 미리보기 빌드 (GitHub Pages 배포용)
```

## 맵 생성과 도달 가능성

- 방 1칸 = 30×17 타일. 방은 1×1 외에 긴 복도(3×1), 큰 홀(2×1, 2×2), 세로 굴(1×2)도 있다.
- 출입구 자리는 좌우 2곳(아래/위), 상하 3곳(왼쪽/가운데/오른쪽). 이웃한 방은 양쪽 템플릿이 모두 가진 자리로 이어진다.
- 템플릿: 손으로 쓴 1×1 44개 + 보스 아레나 3개(`src/rooms/*.txt`), 자동 생성 굴 모양 138개(`src/rooms/gen/`, `node scripts/gen-rooms.mjs`).
- 도달성 검증기(`src/core/generation/reach.ts`)는 게임과 같은 `PlayerMotor`와 타일 충돌 규칙으로 조작을 시뮬레이션한다. 모든 템플릿은 출입구 쌍 이동, 포탈 후보/상자 도달, 빠지면 못 나오는 구덩이 없음을 테스트로 통과해야 한다.
- 좌우로 이어진 방 사이 벽을 양쪽이 빈 높이에서 허물어 한 덩어리 굴처럼 만든다. 층마다 전체 이동을 시뮬레이션해서 검증하고, 실패하면 허물지 않은 층을 쓴다.

## 탐사 요소

- **지름길 문**: 입구에서 먼 쪽 방에 레버(↑ 또는 공격). 당기면 문이 열려 돌아가는 길이 짧아진다. 반대편에서는 열 수 없다.
- **잠긴 방**: 막다른 방의 문이 잠겨 있고, 열쇠는 층 어딘가에 있다. 열쇠를 가지고 문에 다가가면 열리고, 안의 보물 상자는 아이템 선택(높은 등급이 잘 나옴) + 골드.
- **숨은 방**: 막다른 방의 입구가 벽처럼 보이는 부서지는 벽. 안에는 상자가 많다.
- **구역**: 몇 개 방을 묶은 둥지(몬스터와 상자가 많음), 어둠(시야가 좁음), 함정(가시가 많고 상자도 많음).
- 지도에는 지름길/잠긴 문/열쇠가 그 방을 공개하면 표시되고, 구역은 색으로 표시된다.

## 난수 규칙

- `Math.random()` 사용 금지 (`tests/no-math-random.test.ts`가 검사). 모든 게임 랜덤은 `src/core/rng.ts`의 `Rng`(sfc32).
- 층 시드 = `deriveSeed(runSeed, floor)`, 빨간 던전 = `deriveSeed(runSeed, floor, 'red')`.

## 블록과 모서리 잡기

- 맵은 16px 정사각형 블록으로 이루어진다. **벽 색 블록**은 막힌 블록, **더 밝은 블록**은 단방향 블록(위에 설 수 있고, 아래에서 뛰어오르거나 ↓+점프로 통과).
- 스펠렁키식 모서리 잡기: 떨어지는 중에 벽 쪽으로 방향을 넣고 있으면, 위가 비어 있는 막힌 블록의 모서리를 손이 지나가는 순간 붙잡는다. 단방향 블록은 잡을 수 없다. 수치는 `src/config/movement.ts`의 `LEDGE_GRAB`, 판정은 `src/core/movement/ledge.ts`.
