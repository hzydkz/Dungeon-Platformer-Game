# 기획 확인 필요 사항

기획서와 구현이 충돌하거나 기획서가 모호한 지점을 기록한다.
각 항목은 기본값을 적용해 진행했으며, 기획자 확인 후 갱신한다.

| # | 마일스톤 | 내용 | 적용한 기본값 | 상태 |
|---|---|---|---|---|
| 1 | M0 | 기획서는 "Phaser 3 (최신 안정 3.x)"를 지정했으나, 현재 npm `latest` 태그는 Phaser 4.x(4.2.1)다. | 기획서대로 Phaser **3.90.0**(3.x 최신)을 사용. 4.x 전환은 API 차이가 있으므로 별도 결정 필요. | 미확인 |
| 2 | M0 | 런 시드를 "생성"하는 난수 원천. `Math.random()`은 금지되어 있고, 시드 PRNG는 시드가 있어야 돌아간다. | 런 시드 1개만 Web Crypto(`crypto.getRandomValues`)로 뽑고, 이후 모든 랜덤은 시드 PRNG에서 파생. | 미확인 |
| 3 | M0 | `?seed=` 지정을 개발 빌드에만 허용할지(11장 "디버그 기능은 개발 빌드에서만") vs 배포판에서도 허용할지(5.3절). | 개발 빌드에서만 허용. 단, 기획자 테스트용 GitHub Pages 미리보기(`--mode preview`)는 디버그 기능을 켠다. 정식 배포용 `npm run build`는 꺼짐. | 미확인 |
| 4 | M0 | 기획자가 아이패드 + 블루투스 게임패드로 테스트한다. 기획서는 게임패드를 M8에 두었고 조작은 키보드만 정의(4.3절). | 게임패드 입력을 M1으로 앞당겨 구현. Xbox 배치(A 점프, X 공격, B/RB 스킬, View 지도). `config/input.ts`에서 변경. | 기획자 확인 (Xbox 컨트롤러와 동일한 패드) |
| 5 | M1 | 특성 "강철 피부: 이동속도 -10%"는 4장 "모든 역할군 이동 능력 동일, 맵 도달성은 이 이동 능력 기준"과 충돌할 수 있다. | 이동속도 감소를 적용하되, 도달성 검증을 가장 느린 이동속도(×0.9) 기준으로 한다. 점프 높이는 모든 캐릭터가 같다. | 미확인 |
